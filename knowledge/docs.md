## 2026-09-28 Mateo発見: 「予告できない」系の docs 指摘は出力を絞らず実際に走らせて確かめる

`sync-main-checkout.sh --dry-run` の出力には由来の異なる行が混在している
（`-> restart 対象:` = incoming diff からの予告 / `restart-needed(...) [pull 前の現在の
disk 基準]` = 稼働中デーモンと今の disk の比較）。Director の申し送りは後者だけを見て
「dry-run は予告できない」と書いたが、前者は予告できている。隔離した bare origin +
checkout（本番 checkout では絶対に走らせない）で dispatcher.sh を変える commit を
origin に積み、dry-run の全出力を絞らずに貼って確認したことで誤りが分かった（t118）。
grep で「同じ誤りが他にないか」を確認する際も、直した箇所自身の解説文に元の誤り文言を
そのまま引用すると grep 0 件の主張が崩れる — 引用せず言い換えること。
